# ADR 0007：介面風格採用「企業儀表板」

- 狀態：Accepted
- 日期：2026-11-09
- 相關需求：FR-UI-04、FR-UI-13

## 背景

為提升介面的專業感與易用性，規劃了三個風格提案，共用同一套元件與 Token 名稱，只替換語意 Token 的值，並在 `/styleguide` 並排比較。

## 決策

採用 **企業儀表板**（原 `enterprise`）為唯一正式風格。正式規格見 [04 設計語言 §2、§4](../04-design-language.md#4-正式風格企業儀表板)。

理由：Caloud 的主要工作是在表格中掃讀狀態並處理例外。中性的藍灰配色讓狀態色最突出、資訊密度與可讀性平衡，也最不易過時；深藍側欄清楚區隔導覽與內容。

## 考慮過的方案（已移除，規格留存供參考）

| 方案 | 主要規格 | 未採用原因 |
| --- | --- | --- |
| **企業儀表板**（採用） | 強調色 `#1d4ed8`／深色 `#6ea2ff`；側欄 `#0f172a`；系統無襯線；圓角 6／8／10px；控制項 32px | — |
| 開發者終端 | 強調色 `#0e7490`／深色 `#22d3ee`；側欄 `#0f1419`；全介面等寬字；圓角 2／3／4px；控制項 30px；標題前綴 `$ `、大寫標籤 | 中文在等寬字下較寬、長文閱讀吃力；非工程人員較陌生 |
| CAFECA 品牌 | 強調色 `#8e3fa0`／深色 `#ef5da8`；側欄 `#17122b`；主要按鈕品牌漸層；膠囊按鈕；圓角 16／20px；控制項 36px | 漸層與飽和色在資訊密集頁面較搶眼；需與 CAFECA 品牌規範同步維護 |

## 影響

- `web/ds/themes/` 改為單一 `web/ds/theme.css`，以 `:root` 定義淺色、媒體查詢與 `data-theme` 定義深色
- 移除 `data-style` 屬性、`UI.initStyle`、`UI.STYLES`、`?style=` 預覽機制與 styleguide 並排比較區
- 移除只為其他風格存在的 Token：`--heading-prefix`、`--label-transform`、`--label-tracking`、`--color-accent-fill`
- 日後若要支援品牌化（例如對外版本採 CAFECA 品牌色），應以新 ADR 重新引入多主題，Token 名稱沿用現有語意層
